# E-Commerce Customer Segmentation and Churn Prediction

## 📌 Project Overview

This project is an end-to-end Business Analytics solution that analyzes an e-commerce retail dataset to identify customer segments, predict customer churn, and create interactive dashboards for business decision-making.

## 🛠️ Tools & Technologies

- SQL Server
- Python (Google Colab)
- Pandas
- NumPy
- Scikit-learn
- Power BI
- DAX

## 🔄 Project Workflow

1. Data Collection
2. Data Cleaning using SQL
3. Data Analysis using Python
4. RFM Analysis
5. Customer Segmentation
6. Churn Prediction using Machine Learning
7. Power BI Dashboard Development
8. Business Insights and Recommendations

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest

Evaluation Metrics:
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## 📊 Dashboard Pages

### Executive Dashboard
- Revenue KPIs

### Customer Analytics
- Customer Segmentation
- Churn Analysis
- RFM Analysis

### Sales Analytics
- Product Performance
- Monthly Revenue
- Top Countries

### Machine Learning Analysis
- Model Comparison
- Performance Metrics
- Business Recommendations

## 💡 Key Business Insights

- High-value customers contribute the majority of revenue.
- Loyal customers show the lowest churn rate.
- Logistic Regression provided the best overall model performance.
- Customer retention campaigns should focus on high-value customers with churn risk.
